# Brand

The source for the app icon, the DMG window and any later artwork. Written with the
brand skill (`.claude/skills/brand`); update it before changing an asset.

| | |
| --- | --- |
| Product | Name, and what it does for whom in one sentence |
| Promise | The DMG headline: eight words at most |
| Personality | Three words |
| Motif | The object or shape the icon is built on, and why |
| Palette | Primary `#……`, secondary `#……`, light `#……`, ink `#……` |
| Type | SF Pro, SF Pro Rounded or New York, and the weight |

## Icon

The concept in two or three sentences: the layers from back to front, what glows, and
what must survive any revision.

## DMG window

Headline, supporting line, and the shapes or colors that tie it to the icon.

## Avoid

What this brand never looks like.
